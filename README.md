# Санко — самостоятельный чат Поднебесья

Репозиторий веб-интерфейса будущего чата Санко и отдельного VK Mini App.

## Текущий статус (1 ноября 2026)

**Этап 4.2 — исходники Worker Санко созданы в GitHub, но Cloudflare-развёртывание ещё не выполнено.** Страница и адаптивная вёрстка готовы, однако **сервер Санко ещё не подключён**. Введённые в макете сообщения только отображаются в браузере и не отправляются персонажу. Выдаваемые на экране приветствия — новые рабочие примеры, а не буквальные канонические цитаты.

Рабочий чат Олешки находится в **другом** репозитории; его интерфейс и Cloudflare Worker не изменялись.

## Состав

- `index.html` — страница для GitHub Pages и VK Mini App.
- `assets/styles.css` — мобильная и настольная вёрстка.
- `assets/app.js` — локальный предпросмотр, будущий API-клиент, история, VK Bridge.
- `assets/config.js` — публичная конфигурация API, намеренно пустая до успешного развёртывания Worker.
- `assets/forest.svg` — оригинальный декоративный лесной фон.
- `assets/sanko-portrait.jpg` — портрет Санко, предоставленный автором.
- `docs/PROJECT_STATE.md` — зафиксированное состояние и продолжение работы.
- `tests/static-check.mjs` — базовые проверки клиента.
- `worker/src/` — независимый Cloudflare Worker Санко.
- `worker/migrations/0001_init.sql` — схема отдельной D1 Санко.
- `worker/wrangler.toml` — отдельные bindings с placeholders для ID.
- `worker/tests/` — модульные тесты дат, изоляции и API.
- `worker/README.md` — подробный план дальнейшего развёртывания.

## Локальная проверка

Откройте папку через любой статический HTTP-сервер. Для проверки исходников:

```bash
npm test
```

Сервер не требуется для проверки внешнего вида макета; **реальные ответы Санко недоступны** до его подключения.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Предполагаемый адрес после публикации: `https://socman2023.github.io/sanko-chat/`.

## Сервер и знания

Исходники отдельного Worker **`sanko-chat-api` уже созданы**, но не развёрнуты. В нём предусмотрен общий индекс `heroes-knowledge` только с `shared` и `sanko`-фрагментами, а также общее KV `heroes-chat-current` с префиксом `sanko:`. Персональные диалоги, VK-ключи, актуальный контекст и квоты должны быть изолированы от Олешки.

`assets/config.js` содержит только публичный URL будущего Worker. **Никогда не помещайте в GitHub Gemini API key, VK app secret, Cloudflare token, персональные переписки или закрытый канонический корпус.** Пакет Санко v0.2 пока находится вне публичного репозитория для авторского согласования.
