# Санко — самостоятельный чат Поднебесья

Репозиторий веб-интерфейса будущего чата Санко и отдельного VK Mini App.

## Текущий статус (1 ноября 2026)

**Этап 3 — интерфейс-предпросмотр.** Страница и адаптивная вёрстка готовы, но **сервер Санко ещё не подключён**. Введённые в макете сообщения только отображаются в браузере и не отправляются персонажу. Выдаваемые на экране приветствия — новые рабочие примеры, а не буквальные канонические цитаты.

Рабочий чат Олешки находится в **другом** репозитории; его интерфейс и Cloudflare Worker не изменялись.

## Состав

- `index.html` — страница для GitHub Pages и VK Mini App.
- `assets/styles.css` — мобильная и настольная вёрстка.
- `assets/app.js` — локальный предпросмотр, будущий API-клиент, история, VK Bridge.
- `assets/config.js` — публичная конфигурация API, намеренно пустая до этапа 4.
- `assets/forest.svg` — оригинальный нейтральный декоративный лесной фон.
- `docs/PROJECT_STATE.md` — зафиксированное состояние и продолжение работы.
- `tests/static-check.mjs` — базовые проверки целостности и изоляции.

## Локальная проверка

Откройте папку через любой статический HTTP-сервер. Для проверки исходников:

```bash
npm test
```

Сервер не требуется для проверки внешнего вида макета; **реальные ответы Санко недоступны** до его подключения.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Предполагаемый адрес после публикации: `https://socman2023.github.io/sanko-chat/`.

## Сервер и знания

На этапе 4 будет создан **отдельный** Cloudflare Worker `sanko-chat-api`. Планируется использовать общий векторный индекс `heroes-knowledge`, но получать только `shared` и `sanko`-фрагменты. Персональные диалоги, VK-ключи, актуальный контекст и квоты должны быть изолированы от Олешки.

`assets/config.js` содержит только публичный URL будущего Worker. **Никогда не помещайте в GitHub Gemini API key, VK app secret, Cloudflare token, персональные переписки или закрытый канонический корпус.** Пакет Санко v0.2 пока находится вне публичного репозитория для авторского согласования.

## Портрет

Оформление пока использует графический лесной знак. Портрет Санко нужно брать только из утверждённого автором изображения. Подбор и публикация портрета отдельным действием после согласования.

Права на мир, персонажей и изображения принадлежат соответствующим правообладателям. Публичность репозитория не является предоставлением лицензии на авторские материалы.
