# Санко — самостоятельный чат Поднебесья

Репозиторий веб-интерфейса будущего чата Санко и отдельного VK Mini App.

## Текущий статус (2 ноября 2026)

**Рабочая тестовая версия основного чата Санко подключена к отдельному Cloudflare Worker.** Реальный ответ Gemini 3.5 Flash-Lite подтверждён тестом HTTP 200. Веб-интерфейс доступен по адресу https://socman2023.github.io/sanko-chat/. Персональный профиль v0.2 находится на стадии литературного тестирования; приветствия — новые рабочие примеры, а не буквальные цитаты.

Рабочий чат Олешки находится в **другом** репозитории; его интерфейс и Cloudflare Worker не изменялись.

## Состав

- `index.html` — страница для GitHub Pages и VK Mini App.
- `assets/styles.css` — мобильная и настольная вёрстка.
- `assets/app.js` — клиент работающего API Санко, история браузера, будущая интеграция VK Bridge.
- `assets/config.js` — публичный URL отдельного `sanko-chat-api`; секретов в нём нет.
- `assets/forest.svg` — оригинальный декоративный лесной фон.
- `assets/sanko-portrait.jpg` — портрет Санко, предоставленный автором.
- `docs/PROJECT_STATE.md` — зафиксированное состояние и продолжение работы.
- `tests/static-check.mjs` — базовые проверки клиента.
- `worker/src/` — независимый Cloudflare Worker Санко.
- `worker/migrations/0001_init.sql` — схема отдельной D1 Санко.
- `wrangler.toml` — корневая конфигурация нового Worker `sanko-chat-api`, готовая для импорта из текущего Cloudflare без поля Root directory.
- `worker/tests/` — модульные тесты дат, изоляции и API.
- `worker/README.md` — подробный план дальнейшего развёртывания.

## Локальная проверка

Откройте папку через любой статический HTTP-сервер. Для проверки исходников:

```bash
npm test
```

В интерфейсе используются реальные ответы Санко. Локальный просмотр HTML без подключения к интернету не обеспечит общения с Gemini.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Действующий тестовый чат: `https://socman2023.github.io/sanko-chat/`.

## Сервер и знания

Отдельный Worker **`sanko-chat-api` развёрнут и отвечает**. Он использует общий индекс `heroes-knowledge` с фильтром `shared/sanko`, общее KV `heroes-chat-current` с префиксом `sanko:` и самостоятельную D1 `heroes-chat-sanko` для диалогов и лимитов 500/15 000/100. Дальнейшие проверки связаны с характером, полнотой знаний и мобильным интерфейсом.

`assets/config.js` содержит только публичный URL работающего Worker. **Никогда не помещайте в GitHub Gemini API key, VK app secret, Cloudflare token, персональные переписки или закрытый канонический корпус.** Пакет Санко v0.2 пока находится вне публичного репозитория для авторского согласования.
