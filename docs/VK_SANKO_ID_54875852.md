# VK Mini App Санко — App ID 54875852

**Получен App ID: `54875852`.** Это публичный идентификатор приложения, **не идентификатор личной страницы Санко**. `VK_APP_ID` прописан в `wrangler.toml`. Адрес запуска: https://vk.ru/app54875852

## Что уже реализовано

Существующий интерфейс `https://socman2023.github.io/sanko-chat/` отправляет подписанную строку запуска `vkLaunch` на собственный Worker `sanko-chat-api`. Worker проверяет HMAC подпись с помощью **защищённого ключа данного приложения**; только после успешной проверки определяет ID посетителя. Реализована проверка личных отношений Санко в `worker/src/vk-relationships.js` с приоритетом:

**друг → подписчик личной страницы → участник указанного сообщества → незнакомец.**

Списки друзей (`friends.get`) и подписчиков (`users.getFollowers`) запрашиваются только на сервере и кэшируются на **6 часов** в KV с префиксом `sanko:vk:members:`. Это отдельные данные Санко, **не** списки Олешки. Если VK API недоступен, статус не считается проверенным. VK-имя и роль не берутся на веру из параметров браузера; статус друга или подписчика получается только для проверенного VK ID.

## Что необходимо настроить в Cloudflare

Открыть **Workers & Pages → sanko-chat-api → Settings → Variables and Secrets**.

| Переменная | Тип | Значение |
|---|---|---|
| `VK_APP_ID` | обычная / из `wrangler.toml` | `54875852` (уже задано в репозитории) |
| `VK_APP_SECRET` | **Secret** | «Защищённый ключ» именно мини-приложения Санко |
| `VK_OWNER_USER_ID` | обычная | **VK ID личной страницы Санко** (нужен от автора) |
| `VK_SERVICE_TOKEN` | **Secret** | разрешённый токен VK API для чтения друзей и подписчиков страницы Санко |
| `VK_COMMUNITY_ID` | обычная, необязательная | ID отдельного утверждённого сообщества Санко (если нужно узнавать его участников) |

**Ни один секрет не передавать в этот чат и не помещать в GitHub.** Не подставлять `54875852` вместо `VK_OWNER_USER_ID`; не использовать страницу Олешки в качестве страницы Санко. Токен может ограничивать доступ к спискам ВК — после установки обязательно проверить реальные права. Бесплатные тарифы и серверные лимиты не меняются.

## Проверка после установки

1. Зайти в https://vk.ru/app54875852 из ВК и проверить, что страница `https://socman2023.github.io/sanko-chat/` загружается в VK Mini App.
2. Для собственного запуска проверить ответ `POST /api/session` в инструментах разработчика: `verified: true`. При отсутствии `VK_APP_SECRET` будет `verified: false`, даже если App ID правильный.
3. Проверить с аккаунтов друга Санко, личного подписчика и постороннего. Ожидаемые `role`: `friend`, `follower`, `stranger`; `roleChecked` подтверждает завершённую проверку списков. Не показывать приватные списки пользователей в ответе API.
4. Если задан `VK_COMMUNITY_ID`, проверить ещё одного участника сообщества; при совпадениях приоритет всегда остаётся за другом, затем личным подписчиком.
5. Проверить отображение личного приветствия (собеседника нельзя называть по имени, пока его VK ID не проверен), сохранение чата, клавиатуру смартфона и запуск из обычного браузера.

**Ограничение:** эта реализация распознаёт текущие VK-отношения. Она не означает, что Санко запомнил прошлые личные разговоры с конкретным человеком между устройствами: история текущего чата хранится в localStorage клиента. Личность и речь персонажа, хронология и дневник не менялись.

**Статус при создании файла:** App ID внесён; модуль и тесты готовы. До задания VK_OWNER_USER_ID и двух Secret-переменных реальное распознавание в Cloudflare не подтверждено.
