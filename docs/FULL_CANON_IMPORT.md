# Полная персональная база Санко — пересборка 02.11.2026

## Что было не так

Профиль `sanko:profile:v1` был собран по ограниченному списку событий. Санко не узнавал Ясмин/Луну и других лично известных персонажей. Одни короткие специальные подсказки не решают задачу главного героя. Проблема состоит в **неполноте источников и индекса**, а не только в голосе модели.

## Что подготовлено из первоисточников

Текущий полный закрытый пакет `sanko_complete_canon_private_2026-11-02.zip` сформирован **не в публичном GitHub**, а локально из пользовательских файлов:

- `heroes_main.docx`, `heroes.docx` — личные биографии, все присутствующие ученики, учителя и окружение.
- `book1.docx`, `book2.docx`, `book3.docx` — все тексты опубликованных книг.
- `blog.txt` — 1842 полные публикации от 18.02.2024 до 31.10.2026. `blog.docx` проверен отдельно: **все 1842 текста совпадают с blog.txt после нормализации пробелов**, поэтому повторная индексация дубликатов не требуется.
- `academy_first_semester_2026.docx` — занятия, классы, задания, события и 672 строки таблиц.
- `academy_plan.docx` — план Академии.
- `podnebesie_gods.docx`, `podnebesie_calendars.docx`, `podnebesie_peoples.docx` — боги, праздники, летоисчисление, народы и страны (включая 30 строк таблицы народов).

**Итого:** 2975 стабильных текстовых фрагментов с идентификатором, исходным файлом, датой, позицией в тексте и указанием типа документа. Текстовые отрезки перекрываются, их суммарное покрытие каждого первоисточника проверено как **100%, ноль потерянных символов**. **Это разбиение для семантического поиска, НЕ сокращение дневниковой записи в диалоге.** Вечерние публикации по-прежнему читаются Санко полностью из общей D1 Олешки (обновление в 20:30).

Проверено соответствие ограничению Cloudflare Vectorize: максимальный ID 35 байт при разрешённых 64, максимальный размер JSON-метаданных около 4915 байт при 10 KiB. <https://developers.cloudflare.com/vectorize/platform/limits/>

## Архитектура хранения

- Индекс **`heroes-knowledge` остаётся общим**, но все новые векторы из этого пакета имеют метку **`character=sanko`**. Это не даёт новым фрагментам изменять ответы уже работающего Олешки. Профили и чувства разных героев остаются обособленными.
- Полный текст фрагментов хранится в собственной D1 Санко, `heroes-chat-sanko`, таблица `sanko_canon_chunks`. При импорте таблица создаётся в этой базе через защищённый серверный маршрут; D1 Олешки не изменяется.
- Все данные загрузки и поиска остаются приватными в Cloudflare. В публичном GitHub хранятся **только код и статистика корпуса**, без книг и переписки.
- Worker выполняет гибридный поиск: `Vectorize` по смыслу плюс `D1` по русским именам и ключевым словам в нормализованном Unicode-регистре. Есть учёт склонений и предпочтение профильных источников (мир/персонажи/Академия).
- Векторизация — `@cf/qwen/qwen3-embedding-0.6b`, 1024 измерения; используется тот же embedding-тип, что и в имеющемся Worker. Данные индексируются в небольших пакетах из 8 фрагментов, чтобы не перегружать запрос.
- Приоритет источников проекта сохраняется в метаданных (`priority`), однако фактическое разрешение противоречий и личная осведомлённость Санко продолжают требовать проверки качества.

## Как активировать ПОЛНУЮ базу (пока ещё не выполнено)

Автор уже настроил секрет `ADMIN_UPDATE_TOKEN` для отдельного Worker Санко. После успешного Cloudflare deploy новой серверной версии:

1. Открыть `https://sanko-chat-api.boysinger2008.workers.dev/admin/knowledge`.
2. Ввести **свой** `ADMIN_UPDATE_TOKEN` — его не присылать в чат.
3. Выбрать локальный файл `sanko_canon_chunks.jsonl` из закрытого пакета (ZIP необходимо распаковать). Пользовательские тексты НЕ отправлять через GitHub.
4. Нажать «Загрузить в базу Санко». Дождаться прогресса **2975 / 2975** и одинакового числа фрагментов «в базе» / «в поисковом индексе». Сессия работает в браузере и может быть возобновлена с позиции остановки.
5. Проверить несколько десятков вопросов по личной истории, всем книгам, народам, богам, географии, Академии. В том числе «А Ясмин?», «Кто такая Луна?», «Кто Хасим?», «Расскажи про обычаи и праздники славонов», «Чему вас учит Арборис?». Проверить ответы **после нескольких реплик**, а не только на первый вопрос.

**До шага 4** векторы нового корпуса ещё не находятся в живом хранилище. Нельзя говорить, что Санко уже располагает всей этой базой. Тесты GitHub проверяют алгоритм, но не реальные права Cloudflare, доступность Workers AI и последующий полный импорт.

### Оставшиеся риски

- Длительный одноразовый импорт может встретить лимиты Workers AI Free или Cloudflare: остановить загрузку, затем продолжить с сохранённой позиции после сброса лимита; платный тариф не включать без решения автора.
- Профиль `sanko:profile:v1` в KV пока остаётся старой рабочей версией v0.2; в Worker временно включён проверенный слой близких отношений. После проверки корпуса нужно отдельно собрать и согласовать **полный обновлённый персональный профиль**, а не считать загрузку корпуса достаточным доказательством качества.
- Семантический поиск никогда не гарантирует 100% точность каждого ответа. Нужен предметный тест узнавания имён, исторических фактов, Богов и личного POV. Не переносить личные тайны и субъективные чувства Олешки в память Санко автоматически.
- Авторский принцип: **Санко — равноправный главный герой с полноценным знанием Поднебесья; он должен оперировать всей общедоступной хроникой и всеми общими знаниями мира, говоря собственным голосом.** Подтверждённые периоды разлуки с Олешкой остаются исключениями для рассказа от первого лица.
