## Этап 4.8 — полный текст дневника без обрезки (02.11.2026)

- **Коренная ошибка была допущена в Worker Санко, а не в обновлении дневника Олешки.** Ассистент изначально установил обрезку `source_text` до 1900 символов, затем ошибочно заменил её «почти полным» текстом до 16 000, оставил общий порог 30 000 символов и `systemText().slice(0,62000)`. Из-за этого Санко упускал вторую половину полноценной записи.
- **Фактически подтверждено владельцем 02.11.2026:** `GET /health` вернул `diarySync.status=ok`, `latestPostDay=2026-11-02`, `latestPublishedAt=2026-11-02T17:00:01.000Z` (**20:00:01 МСК**), `latestIngestedAt=2026-11-02T17:30:29.000Z` (**20:30:29 МСК**) и `postsToday=1`. Значит, опубликованная запись уже находилась в D1. Версия Worker на момент проверки — `sanko-worker-0.2.1`.
- **Постоянное правило проекта, подтверждённое автором:** вечерняя запись обычно публикуется в **20:00 МСК**, а её штатная проверка выполняется **в 20:30 МСК всегда**. Не объяснять отсутствие второй части записи гипотезами о трёхчасовой задержке, когда D1 прямо подтверждает своевременную загрузку.
- В `worker/src/index.js` (версия **sanko-worker-0.2.2**) убраны **все ограничения на количество символов текста выбранной записи**: `diaryBody()` не меняет и не обрезает `source_text`; отменены пороги 16 000 символов на запись, 30 000 символов для выбранных записей, количество выбранных публикаций на этапе формирования контекста и конечный `slice(0,62000)` всей системной инструкции.
- Для конкретной даты и сегодняшнего дня D1-запрос выбирает **все записи за этот день без SQL LIMIT**. Для прочих исторических событий количество **выбираемых** записей ограничено при поиске, но каждая выбранная запись передаётся целиком. Это не загрузка всего многолетнего архива за один запрос.

## Контрольные настройки

- API в `assets/config.js` подключён к **отдельному** `sanko-chat-api`; возвращать его на Worker Олешки нельзя.
- Локальное хранилище `sanko-native-chat-v1` изолировано от `oleshka-native-chat-v1`.
- Никогда не подключать API Олешки для «временной проверки».
- Не приписывать Санко сведения, которыми владеет только Олешка.
