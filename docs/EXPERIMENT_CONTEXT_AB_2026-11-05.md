# Санко: эксперимент с выборочным контекстом — 05.11.2026

## Статус: только эксперимент, НЕ публикация

- Основа: утверждённая действующая `main`, Worker `sanko-worker-0.6.15`.
- Изменения только в ветке `experiment/context-selection-no-deploy-20261105`, Draft PR #35. В `main`, Cloudflare Worker и чате Олешки **не менялось ничего**. Версия Worker специально оставлена прежней, чтобы случайно не выдать прототип за выпуск.
- Сведения из реальных журналов владельца: systemChars=115 934, в составе 51 801 символ дневника (12 полных записей), 29 090 профиля, 13 477 результатов RAG, 3 409 актуального KV, 1 400 повторно скопированных символов. Gemini реально измерила 38 317 входных токенов при одном из коротких ответов; другая попытка получила HTTP 503 и не вернула токены.

## Принцип изменения

Никаких удалений канонических документов, редактирования дневника, замены модели, речевых форм, выключения лимитов или переопределения событий. Меняется только набор **уже утверждённых источников**, который отправляется в генерацию.

- **Точное приветствие**: сохранены личность, полный действующий голос Санко, правила дат и отношения к подтверждённому собеседнику, актуальный KV; полные архивные записи, общий 29-тысячный профиль и поиск отключены.
- **«Как дела?»** и другая узко распознаваемая бытовая реплика без предшествующей фактической темы: краткая личность + актуальный KV + **последняя полная запись** дневника.
- **«Что нового?»**: краткая личность + актуальный KV + **четыре последние полные** опубликованные записи. Не две: автору важна полнота свежих событий.
- **Вопрос о конкретном персонаже/событии**: полный прежний профиль, личные подтверждённые отношения, RAG и последние 2 полные дневниковые записи плюс до 5 тематически подходящих полных записей. Имена ищутся с учётом простых русских окончаний (Руман/Румана/Руману).
- **Подробный тематический вопрос**: полный профиль + RAG + 3 последние записи и до 10 тематических публикаций.
- **«А потом?»** и другие неоднозначные продолжения: сохраняется полный современный архивный контекст — качество важнее экономии, предыдущий **вопрос** пользователя применяется для поиска; собственные реплики модели источником канона не становятся.
- **Запрос с явной календарной датой**: все утверждённые записи запрошенного дня полностью; режим дат/хронологии неизменен.
- **Пояснение «Чего „опосля“?» после предыдущей реплики**: не требуется вся библиотека, но сохраняются утверждённый говор, предыдущая история и специальное правило осмысленного пояснения.
- Удалена копия до 4 × 1 400 символов свежего дневника, которую Worker раньше добавлял после уже включённых полных текстов.
- Диагностика размеров контекста сохраняется; `focusRepeatChars=0` и `profileChars` соответствует действительно переданному профилю. Для отчётности добавлены `contextMode` и `fullProfileAvailableChars`, без текстов запросов/ответов.

## A/B сравнение на одной и той же тестовой базе

Два Worker загружаются GitHub Actions из **двух отдельных checkout**: исходный `main` и экспериментальный PR. Обоим подаются **одинаковые** синтетические D1 (12 записей по 4 300 символов), KV профиль (29 090 символов), личный контекст (3 409), Vectorize, история и вопросы; Gemini подменена одинаковым детерминированным mock. Результаты: **размер системного промпта в символах**, а не оплаченные Gemini токены.

Числа включают повторную отправку системного блока при каждом ходе. Это не измеренные расходы в токенах и не денежный биллинг.

Проверки автоматически отбрасывают эксперимент, если пропал конец любого выбранного полного поста, целый день по явной дате, старые найденные записи о Румане, полный личный профиль в предметном вопросе, основные правила голоса и вера в Варока, актуальный контекст или тематическая непрерывность восьмиходового разговора.

GitHub Actions: `Sanko source tests` и `Sanko context A/B — offline, no deployment` должны быть зелёными до любой дальнейшей работы.

## Что ещё НЕ доказано и почему пока не включать в основной Worker

- Исходные данные для A/B взяты из **синтетических тестовых источников с реальными размерами**, не из приватной D1 пользователей; тесты не воспроизводят все реальные проблемы поиска и пересечения дат/событий.
- Mock Gemini даёт заранее известный ответ, поэтому **не проверяет художественную естественность, точность канона и логику речи** в оптимизированной версии. Реальная стоимость входа зависит от токенизатора и не равна длине промпта в символах.
- Для утверждения качества нужно сравнить реальные ответы Gemini на одинаковых многоходовых вопросах в **изолированной тестовой среде** с той же актуальной D1/KV, сохранив утверждённый канон. В момент реализации доступ к секрету Gemini и закрытой D1 через GitHub Actions отсутствует. **Не копировать секреты в репозиторий и не делать общедоступный тестовый endpoint.**
- Тестовая рубрика: актуальная хронология после 31.10, роль Санко в каждом событии, Руман/Элина, отец и Ясмин, обязательный говор без словесной каши, «Слава Вароку», понимание замечания «не понял», диалог с подтверждённым Олешкой. Сравнить реальные входные токены, количество попыток, ошибки, время и содержательную точность.
- По этой причине PR #35 остаётся **Draft** и не должен быть объединён или развёрнут. Улучшать Олешку аналогично можно только после подтверждения результатов Санко и проверки последней действующей версии Олешки.
