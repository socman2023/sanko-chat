# Санко 0.6.16 — выборочный канонический контекст (05.11.2026)

Статус: релизное изменение Worker, направляемое в `main` по прямому указанию владельца «Развертывай исправления в обычном чате». **Не** переносить в `main` код приватной тестовой страницы, систему Preview и дополнительные настройки secrets из экспериментального PR #35.

## Основа

- Исходная версия `sanko-worker-0.6.15`.
- Аудит реального запроса Gemini: системный контекст 115 934 символа, из них дневник 51 801, профиль 29 090, RAG 13 477, повтор 1 400; при успешной Gemini 3.1 Flash Lite 38 317 входных и 33 выходных токена.
- Экспериментальная ветка `experiment/context-selection-no-deploy-20261105`, но в релизный PR перенесены **только изменения формирования контекста** и необходимые тесты, без Preview-логики.

## Что изменено

- `worker/src/context-selection.js`: точные приветствия получают сокращённую идентичность и текущий KV без излишнего RAG/дневника; обычные социальные вопросы — краткую идентичность и последнюю полную публикацию; «Что нового?» — четыре последних **полных** опубликованных дневниковых текста, чтобы не потерять ход событий; конкретные люди/приключения — полный личный профиль, тематические полные записи и RAG; неоднозначные продолжения — полный актуальный контекст; вопросы с точной датой — все источники даты по старому механизму.
- Удалено дублирование до 5 600 символов свежего дневника, уже переданного полностью. В журнале `focusRepeatChars=0`.
- Сохраняются все речевые ограничения, отношение к подтверждённому Олешке, «Слава Вароку», актуальный KV, строгий канон и правила незнания фактов.
- При использовании русских изменяемых имён (Руман/Румана/Руману, Мстислав/Мстиславом) тематический поиск учитывает распространённые окончания.
- Диагностика размеров контекста сохраняется, добавлен `contextMode`.

## Безопасность и откат

Никакого изменения `wrangler.toml`, D1 миграций, секретов, quota/admission, Gemini fallback, UI или VK подписей. Если качество заметно ухудшится, возврат к исходной версии 0.6.15 должен происходить через Cloudflare deployments rollback или revert релизного PR. **Не возвращаться к старым версиям по памяти.**
