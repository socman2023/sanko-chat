## Что добавлено в код

- `worker/src/profile-admin.js`: защищённые административные операции чтения статуса, установки и возврата последней резервной копии профиля в уже существующем `CURRENT_CONTEXT`.
- В `worker/src/admin.js`: `POST /admin/profile/status`, `POST /admin/profile/activate`, `POST /admin/profile/restore`. Доступ только по `ADMIN_UPDATE_TOKEN` и той же origin-политике, что и остальная админпанель. Ни одно действие не затрагивает KV Олешки.
- `GET /admin/profile` — раздел для выбора локального файла, сознательного подтверждения установки и отката.
- Автоматические тесты `worker/tests/profile-admin.test.mjs`: авторизация, запрет чужих origin, проверка объёма, наличие обязательных фактов, резервирование, восстановление, отсутствие доступа к ключам `oleshka:`, синтаксис панели.
- При активации версия `v0.4.0` принимается в исходный KV-ключ **`sanko:profile:v1`** — имя ключа остаётся прежним ради совместимости чата. Это НЕ означает, что там содержится редакция v0.1.

## Как опубликовать после авторской проверки

1. Распаковать приватный пакет `SANKO_PROFILE_v0.4_REVIEW_PACKAGE.zip`. Изучить файл `SANKO_PROFILE_v0.4_AUTHOR_REVIEW.txt` и отчёт об основаниях.
2. Открыть **<https://sanko-chat-api.boysinger2008.workers.dev/admin/profile>**, ввести действующий секрет `ADMIN_UPDATE_TOKEN` *на самой странице* (не присылать секрет в чат).
3. Сверить текущую версию/длину/контрольную сумму. Выбрать новый текстовый файл и нажать «Опубликовать профиль в KV», подтвердив действие.
4. Панель возвращает SHA-256 нового текста; ожидаемое значение: `ff544ad6f22e184fd646cfad78bc7a5693f8a143efdd2c1430e7a58d89bf3832`. KV может распространять новое значение между точками Cloudflare не мгновенно.
5. Если выявится критическая ошибка, в том же разделе нажать «Вернуть предыдущий профиль». Старый текст резервируется автоматически перед каждой заменой.
6. Проверить ответы по личной истории, всем трём классам, прошлым книгам и народам/богам/календарям; использовать [матрицу из 28 сценариев](SANKO_CANON_QA.md). Спорные факты сохранять в отдельном листе на авторское согласование.

- Создание кода администрирования **не обновляет автоматически** действующий KV и не подтверждает живые ответы Gemini.
