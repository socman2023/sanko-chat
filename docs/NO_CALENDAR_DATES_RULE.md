# Авторское правило: в ответах героев нет календарных дат

Олешка и Санко никогда не произносят в персонажных репликах календарные даты, включая год, месяц и день недели, даже по просьбе собеседника. Даты допустимы только для внутренней хронологии, поиска и диагностики. В разговоре допустимы «нынче», «вчера», «давеча», «завтра».

Санко: Worker v0.5.6, правило и проверка в `worker/src/sanko-voice.js` и `worker/src/reply-guard.js`. Живой прогон: https://github.com/socman2023/sanko-chat/actions/runs/41738335342 — успешен, два ответа краткие и без дат.

Олешка: та же норма в `socman2023/oleshka-chat/docs/NO_CALENDAR_DATES_IN_HERO_SPEECH.md`. Рабочий Worker 3.9.2 без изменений: исходник отсутствует в GitHub, нельзя заменять его старым кодом.
