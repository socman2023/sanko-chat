# Санко — выпуск VK Mini App

**Статус:** мини-приложение Санко создано: **App ID `54875852`**, личная страница Санко — **VK ID `1029851985`**. Оба публичных идентификатора добавлены в `wrangler.toml`. Работа внутри VK по скриншоту подтверждена; реальное определение статусов друзей и подписчиков по VK API ещё требуется проверить.

## Архитектура — без дублирования проекта

- Обычная веб-страница: **https://socman2023.github.io/sanko-chat/**
- Адрес для VK Mini Apps (в том числе мобильный, desktop и мобильный веб-клиент): **https://socman2023.github.io/sanko-chat/**
- Сервер: отдельный `https://sanko-chat-api.boysinger2008.workers.dev`; другой Worker Олешки не используется.
- Обновления интерфейса делаются в **одном** репозитории `socman2023/sanko-chat`. Сайт по обычной ссылке остаётся доступным.
- Обязательных платных подписок, покупок или монетизации не предусматривается. Действуют прежние серверные бесплатные квоты.
- История диалога хранится локально в браузере/WebView. Это **не** синхронизация между устройствами и браузерами; ВК может очистить локальное хранилище.

## Что делает VK-версия

- VK Bridge подключён по закреплённой версии `2.15.12`, отправляет `VKWebAppInit`, принимает `VKWebAppUpdateConfig` и использует безопасные отступы.
- Интерфейс показывает разговор **сразу**, даже если VK Bridge или проверка сессии работают медленно либо недоступны. Посетитель не должен видеть пустой экран.
- В широком десктопном iframe ВКонтакте (viewport от 800 px в ширину и от 560 px в высоту) отображаются **две колонки**: слева портрет, лесной фон и описание Санко, справа переписка — как в браузерном чате. В узком или низком WebView боковая панель скрывается, чтобы не теснить сообщения и клавиатуру. Переход зависит от размеров **самого iframe**, а не внешнего окна браузера.
- В обычном браузере без VK-параметров остаётся исходный двухколоночный дизайн. Используется тот же API и история.
- Подписанные параметры запуска передаются только собственному Worker по HTTPS. Имя и роль посетителя не принимаются на веру из браузера: сервер должен проверить `sign` и `vk_app_id` при наличии `VK_APP_SECRET`.
- На первом этапе **не запрашиваются разрешения на публикацию, персональные контакты или оплата**. Серверная проверка дружбы и подписки реализована, а VK ID Санко уже настроен. Для её фактической работы остаются разрешённый `VK_SERVICE_TOKEN` и проверка ответов VK API.

## Создание приложения в кабинете VK

1. Открыть [кабинет разработчика VK](https://dev.vk.ru/) и создать отдельное **встраиваемое приложение / VK Mini Apps** (не приложение для выплат). Не брать App ID у «Олешки», карты или игр.
2. Название: **«Разговор с Санко»**. Категория: **«Развлечения»**, либо близкая категория, если название в кабинете изменилось.
3. В размещении приложения указать один и тот же URL `https://socman2023.github.io/sanko-chat/` для desktop, мобильного приложения и `m.vk.ru`. Все адреса — HTTPS.
4. **App ID получен: `54875852`**. В Cloudflare Worker `sanko-chat-api` установить **`VK_APP_SECRET` как Secret** (публичный `VK_APP_ID` уже в `wrangler.toml`). Секрет брать из пункта **«Защищённый ключ»**, не путать с сервисным ключом API. Не передавать этот ключ в чат и не сохранять в GitHub.
5. Открыть новое мини-приложение через `https://vk.ru/app54875852`. Убедиться, что VK Bridge инициализируется, а `POST /api/session` действительно отвечает `verified: true` для неподдельного запуска. Не выводить в публичные логи полную строку `vkLaunch` или секрет.
6. Проверить мобильный VK, настольный VK, `m.vk.ru` при необходимости, узкий и широкий экраны Samsung Galaxy Z Fold 5; открытие клавиатуры, отправку сообщения, новый разговор, сохранение текущей истории и серверные ограничения. После успешного теста загрузить оформление и отправить на модерацию.

Для раздела **«Отображение»** предпочесть элементы управления **над окном**, чтобы панель VK не закрывала заголовок и сообщения Санко (точное название пункта зависит от текущего кабинета).

Подключение узнавания друзей и подписчиков: [VK_SANKO_ID_54875852.md](VK_SANKO_ID_54875852.md). До завершения серверной настройки нельзя объявлять распознавание работающим.

## Оформление и проверка перед модерацией

В кабинете ВК потребуются **иконка, скриншоты и изображения для карточки/сниппета**, в размерах, которые кабинет укажет именно для этого приложения. Для основы можно использовать уже утверждённый портрет `assets/sanko-portrait.jpg` и существующий дизайн, но не подменять его неутверждённым изображением. Снимки нужно делать из настоящего VK-клиента после регистрации приложения: мобильный узкий/широкий экран и десктоп, без технических ошибок и личной переписки других людей.

**Не сделано/не проверено до получения App ID:** авторизация подписанного VK запуска с реальным ключом; VK ID Санко и его друзья/подписчики; проверка в реальном VK WebView/iframe; скриншоты из VK и модерация. Это не мешает обычному веб-чату.
